# Changelog

All notable user-visible changes to the SilverBullet TOS application package.

## 2.12.1-1 — 2026-11-14

### Added
- First release. SilverBullet (`zefhemel/silverbullet:2.12.1`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8137 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/silverbulletdocker/`.
